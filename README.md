# Gulf-War — حرب الخليج

لعبة أكشن جانبية تجريبية لأندرويد، بشخصيتين يمكنهما اللعب معًا على نفس الواي فاي أو الهوت سبوت، بدون إنترنت. الإصدار 0.3 يستخدم رسومات السوق الصحراوي والشخصيات والزعيم التي عُرضت في معاينة المشهد المعتمدة.

## أين ألعب؟

- **تجربة المتصفح الفردية:** https://emadmedo19.github.io/Gulf-War/ بعد نجاح النشر وتفعيل GitHub Pages.
- **ملف أندرويد:** افتح [Actions](https://github.com/emadmedo19/Gulf-War/actions)، ثم آخر تشغيل ناجح لـ **Build Gulf-War**، وحمّل **Gulf-War-Android-APK** من Artifacts. فك الضغط وثبّت APK على الجهازين. تحتاج تسجيل الدخول إلى GitHub لتنزيل Artifacts. ملف التجربة موقع بمفتاح تطوير مؤقت؛ قد تحتاج حذف الإصدار السابق لتثبيت إصدار من تشغيل آخر.
- إذا تعطل نشر Pages، اختر **Settings → Pages → Source: GitHub Actions** ثم أعد تشغيل الـ workflow. نجاح رفع المشروع لا يعني أن رابط اللعب قد نُشر.

## اللعب

على الهاتف استخدم أزرار الشاشة: اتجاهان، قفز، إطلاق نار، قنابل. على الكمبيوتر: A وD للحركة، Space للقفز، J لإطلاق النار، K للقنابل، Escape للقائمة. زر الرجوع في أندرويد يعيدك للقائمة. بعد الفوز أو الخسارة ارجع وابدأ جولة جديدة.

### لاعبان على أندرويد

1. وصّل الجهازين بنفس الواي فاي، أو افتح هوت سبوت على أحدهما ووصل الثاني به.
2. على الأول اختر **HOST**. ستظهر عناوين IP المتاحة؛ استخدم عنوان اتصال الواي فاي أو الهوت سبوت.
3. اكتب العنوان على الثاني ثم اختر **JOIN**. تبدأ الجولة عند الاتصال.

المتصفح يقدم تجربة فردية فقط لأن اتصال ENet/UDP يحتاج نسخة أندرويد أو سطح المكتب. البلوتوث غير منفذ. بعض الشبكات تعزل الأجهزة؛ استخدم شبكة تسمح باتصال الأجهزة ببعضها. المنفذ UDP 24765. نجح اختبار اتصال نسختين فعليتين من المحرك عبر ENet على الجهاز المحلي، مع إرسال تحكم اللاعب الثاني واستقبال حالة المضيف. الاتصال والأداء على موبايلين فعليين لم يُختبرا بعد.

## المحتوى الحالي

مرحلة مدينة صحراوية واحدة، حركة وقفز وإطلاق نار وخمس قنابل لكل لاعب، تسعة أعداء وزعيم مدرع، صحة ونقاط وفوز وخسارة. أضيفت حركة الجري والقفز والتسارع، حركة للأعداء والزعيم، شرر ودخان وانفجارات وفوارغ طلقات وأصوات اصطناعية قصيرة. الزعيم يتحرك كرسمة كاملة مع اهتزاز وارتداد؛ ليس لديه تحريك مستقل لكل مفصل. المراحل الإضافية لا تزال قيد التطوير.

## التطوير

افتح `project.godot` في **Godot 4.6.3** وشغل F5. إعدادا تصدير Android وWeb موجودان. يبني GitHub Actions النسختين تلقائيًا عند الدفع إلى main. نسخة أندرويد Debug للتجربة وليست إصدار متجر.

اختبار آليات اللعب:

```sh
godot --headless --path . --script res://tests/smoke.gd
```

الاختبار يغطي الحركة والقفز والأسلحة والقنابل والضرر ومدخلات اللاعب الثاني والفوز والخسارة؛ لا يثبت نجاح الشبكة على أجهزة فعلية.

## فحوصات الإصدار 0.2

```sh
godot --headless --path . --script res://tests/action.gd
python3 tests/network_test.py
```

المحاكاة تعمل عند 60 خطوة في الثانية، مع تنعيم مواضع العرض والكاميرا وتحديث حالة الشبكة عند 30 مرة في الثانية. هذا هدف تقني للمحاكاة ولا يضمن 60 إطارًا في الثانية على كل هاتف. المؤثرات محدودة بـ220 عنصرًا. صور WebP هي نفس الرسومات المعتمدة بعد ضغط حجم الملفات، وتبقى منفصلة عن الشخصيات المتحركة.

## تحديث 0.3 المستند إلى المقطع المرجعي

- ساحة كهف: زر CAVE في القائمة يفتحها في الوضع الفردي. في اللعب الجماعي، يبدأ اللاعبان في المدينة؛ بعد هزيمة الزعيم اضغط إطلاق النار بعد ظهور رسالة الفوز للانتقال معًا إلى الكهف.
- أربع موجات إضافية أثناء التقدم، تتضمن جنودًا ودرونز ومدرعات أرضية. التصويب يساعد تلقائيًا على استهداف أقرب عدو أمام اللاعب، بما في ذلك الأهداف الجوية.
- SKILL / زر L: مهارة كهربائية زرقاء عند اكتمال الطاقة؛ تعطي حماية قصيرة وتضرب الأهداف القريبة. القتل وجمع العملات يعيدان شحن الطاقة.
- عملات تتحرك نحو اللاعب، وأرقام ضرر؛ كل خمس عمليات قتل تسقط ترقية HEAVY تعطي انتشار طلقات مؤقتًا.
- أصوات اصطناعية منفصلة وموسيقى قصيرة أصلية، مع زر SND أو المفتاح M لكتم الصوت. هذه ليست نسخة من التسجيل الصوتي في الفيديو المرجعي.
- موجات الكهف وأسلوب الرسومات يعتمدان على أصول Gulf-War الأصلية. هذه نسخة تجريبية مطورة باتجاه المرجع، ولا تعيد جميع أنظمة Metal Slug Code: J أو تحريكها أو محتواها.
- تُفحص بصمات ملفات الوسائط، ثم تُفتح الصور والموسيقى من داخل بيانات APK ونسخة المتصفح قبل إتاحة التنزيل.

```sh
godot --headless --path . --script res://tests/reference_combat.gd
```
