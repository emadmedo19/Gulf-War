# Gulf-War — حرب الخليج

لعبة أكشن جانبية تجريبية لأندرويد، بشخصيتين يمكنهما اللعب معًا على نفس الواي فاي أو الهوت سبوت، بدون إنترنت. الرسومات الحالية مبدئية وليست الرسومات النهائية المعروضة في التصور.

## أين ألعب؟

- **تجربة المتصفح الفردية:** https://emadmedo19.github.io/Gulf-War/ بعد نجاح النشر وتفعيل GitHub Pages.
- **ملف أندرويد:** افتح [Actions](https://github.com/emadmedo19/Gulf-War/actions)، ثم آخر تشغيل ناجح لـ **Build Gulf-War**، وحمّل **Gulf-War-Android-APK** من Artifacts. فك الضغط وثبّت APK على الجهازين. تحتاج تسجيل الدخول إلى GitHub لتنزيل Artifacts. ملف التجربة موقع بمفتاح تطوير مؤقت؛ قد تحتاج حذف الإصدار السابق لتثبيت إصدار من تشغيل آخر.
- إذا تعطل نشر Pages، اختر **Settings → Pages → Source: GitHub Actions** ثم أعد تشغيل الـ workflow. نجاح رفع المشروع لا يعني أن رابط اللعب قد نُشر.

## اللعب

على الهاتف استخدم أزرار الشاشة: اتجاهان، قفز، إطلاق نار، قنابل. على الكمبيوتر: A وD للحركة، Space للقفز، J لإطلاق النار، K للقنابل، Escape للقائمة. زر الرجوع في أندرويد يعيدك للقائمة. بعد الفوز أو الخسارة ارجع وابدأ جولة جديدة.

### لاعبان على أندرويد

1. وصّل الجهازين بنفس الواي فاي، أو افتح هوت سبوت على أحدهما ووصل الثاني به.
2. على الأول اختر **HOST**. ستظهر عناوين IP المتاحة؛ استخدم عنوان اتصال الواي فاي أو الهوت سبوت.
3. اكتب العنوان على الثاني ثم اختر **JOIN**. تبدأ الجولة عند الاتصال.

المتصفح يقدم تجربة فردية فقط لأن اتصال ENet/UDP يحتاج نسخة أندرويد أو سطح المكتب. البلوتوث غير منفذ. بعض الشبكات تعزل الأجهزة؛ استخدم شبكة تسمح باتصال الأجهزة ببعضها. المنفذ UDP 24765. الاتصال بين موبايلين فعليين لم يُختبر بعد.

## المحتوى الحالي

مرحلة مدينة صحراوية واحدة، حركة وقفز وإطلاق نار وخمس قنابل لكل لاعب، تسعة أعداء وزعيم مدرع، صحة ونقاط وفوز وخسارة. المراحل الإضافية والأصوات والرسومات والتحريك النهائي ما زالت تحتاج تطويرًا.

## التطوير

افتح `project.godot` في **Godot 4.6.3** وشغل F5. إعدادا تصدير Android وWeb موجودان. يبني GitHub Actions النسختين تلقائيًا عند الدفع إلى main. نسخة أندرويد Debug للتجربة وليست إصدار متجر.

اختبار آليات اللعب:

```sh
godot --headless --path . --script res://tests/smoke.gd
```

الاختبار يغطي الحركة والقفز والأسلحة والقنابل والضرر ومدخلات اللاعب الثاني والفوز والخسارة؛ لا يثبت نجاح الشبكة على أجهزة فعلية.
